Política de Privacidade – Sorteio Liga

Última atualização: 21 de outubro de 2026.

O que é

O Sorteio Liga é uma ferramenta usada apenas pela própria liga acadêmica para sortear prêmios entre as pessoas que comentaram nas publicações do seu perfil no Instagram.

Quais dados usamos

Usamos somente o nome de usuário e o texto dos comentários feitos nas publicações da conta da liga, obtidos pela API oficial do Instagram, com autorização da própria conta.

Como usamos

Os dados servem apenas para conferir as regras do sorteio (por exemplo, número de marcações) e escolher os ganhadores. O processamento acontece no navegador de quem opera o sorteio.

Armazenamento e compartilhamento

Não mantemos servidor nem banco de dados. Não vendemos nem compartilhamos dados com terceiros. Apenas os nomes de usuário dos ganhadores são divulgados no anúncio do resultado.

Exclusão de dados

Como não guardamos dados em servidores, não há nada a excluir do nosso lado. Para qualquer pedido ou dúvida, escreva para lacpeduni9@gmail.com.
